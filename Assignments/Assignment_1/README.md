# Assignment 1 – C Programming

## Description

This folder contains five C programming solutions completed as part of the Logic Building with Industrial Project Development batch.

The programs focus on fundamental C programming concepts, loops, conditional statements, functions, and input/output operations.

## Programs List

| No. | Program Name | Concepts Used |
|---|---|---|
| 1 | Division of Two Numbers | User-Defined Function, Arithmetic Operators |
| 2 | Display Marvellous Five Times | For Loop, Function |
| 3 | Display Numbers from 5 to 1 | While Loop, Decrement Operator |
| 4 | Check Divisibility by 5 | Boolean Data Type, If-Else, Modulo Operator |
| 5 | Display Asterisks | For Loop, Function, User Input |

## Program Details

### 1. Division of Two Numbers
- Accepts two integer values.
- Performs division using a user-defined function `Divide()`.
- Handles division by zero.

### 2. Display Marvellous Five Times
- Uses a `for` loop.
- Displays the word `Marvellous` five times.

### 3. Display Numbers from 5 to 1
- Uses a `while` loop.
- Prints numbers in descending order from 5 to 1.
- Uses the decrement operator.

### 4. Check Divisibility by 5
- Accepts an integer from the user.
- Checks divisibility using the modulo operator `%`.
- Returns a Boolean result.

### 5. Display Asterisks
- Accepts a number from the user.
- Uses a `for` loop to display the `*` character according to the entered number.
